Owner direction: improve the whole Android and Studio experience, with Gemini, Grok, ChatGPT and other assistants as interaction references. Preserve Meshlit's identity and real capability boundaries; do not copy branding or assets.

## Review principles

Chat remains the main task. Keep the message area quiet, one obvious Send/Stop control, a visible model/source, a retained draft and predictable back navigation. Put setup and advanced controls behind deliberate entry points. Explain waiting/failure with an actionable next step. Search spans settings categories; source/service names remain searchable even when controls are consolidated. Preserve theme, font scale, contrast and permission preferences.

## Concrete changes

- Remove the full-screen boot/model gate after legal acceptance. The workspace opens while model loading continues, and actual model status remains visible. Sending stays gated on real readiness; navigation no longer needs an extra “Open app while loading” tap.
- Empty chat distinguishes ready/loading/no-model states. Ready chats offer Explain/Plan/Write suggestions that fill and focus the draft without sending. Loading provides model status and navigation; no-model state offers a direct model chooser.
- Keep new connected-memory/automation setup collapsed until requested. Enabled service actions and admitted-job Stop controls remain separate. Group roles, teams, knowledge, model providers and phone actions through Connected capabilities instead of duplicating their backends.
- Remove unused full role payloads, legacy knowledge selectors, acoustic agent-modem controls and unrelated wallet/lab launcher routes from the main product flow. Preserve historical data and underlying source where appropriate.
- Studio provides the same named role/team/connected-capability destinations. Webviews use textContent for external output, scoped scripts, readable native theme variables and keyboard focus outlines.

Studio also adds a live System resources page with CPU/RAM gauges, two-minute history, model/backend memory, power/GPU observations and a process table. Controls distinguish planned and applied thread hints, pause actual polling and stop the owned model. Advanced workload settings are collapsed. Unavailable readings stay unknown rather than displaying invented zeroes.

## Primary design references

- [Google Design: Gemini visual design](https://design.google/library/gemini-ai-visual-design): visual hierarchy and coherent shapes; no Google assets reused.
- [Grok product help](https://help.x.com/en/using-x/about-grok): an accessible conversational entry point; no benchmark or privacy claims carried into Meshlit.
- [ChatGPT release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes): conversational navigation and composer discoverability as references, not a pixel template.

Further source changes retain unsent text per conversation in the same private app history as messages, restore it when switching chats and exclude it from explicit conversation export. Draft writes are debounced; a sudden process loss can still lose the last fraction of a second. Photos are not persisted as draft attachments. An app-wide Overdrive+ banner remains visible independently of optional notification/sound preferences.
