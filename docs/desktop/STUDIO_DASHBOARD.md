# Studio dashboard

The desktop client opens the dashboard at launch. Search by feature or choose a management category. **Settings** opens preferences and **Open coding IDE** opens the editor in its own window. The main dashboard remains usable while a project is open. Chat and the IDE share the existing conversation.

In the Code OSS edition, an empty window opens the management dashboard by default. **Open coding IDE** lets you choose a project and opens its folder in a separate window after project review. An explicitly saved Chat or Editor startup preference still takes precedence. In Settings, select a category to narrow search results or use **Clear** to browse everything again.
