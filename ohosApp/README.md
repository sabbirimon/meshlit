This is the **26.0.0 SDK / latest NEXT native ecosystem** target, not a legacy
HarmonyOS Android APK. English is the default; 简体中文 and appearance settings
are persisted. The native capability adapter correctly reports local LLM runtime
unavailable until a separately compiled and tested engine is integrated.

Open this directory with the current official DevEco Studio/26.0.0 SDK. Configure
signing locally. The project's Stage/Hvigor configuration is provisional until
checked with that SDK. No DevEco SDK or NEXT hardware is present on the development
Mac; no HAP/native build or device acceptance is asserted.

See [platform boundary, security and setup](../docs/MULTIPLATFORM_NEXT.md).
